# Privacy Policy — Find the Spy

This repository hosts the public Privacy Policy for the **Find the Spy** mobile
game (`com.narek.whosoutoftheloop`).

- Published page: https://narekv-games.github.io/privacy-policy/
- Effective date: August 4, 2026
- Contact: vardapetyannarek0@gmail.com

The page is a single self-contained `index.html` with no external assets. The
same policy text is shown inside the app on the *Settings → Privacy Policy*

the source of truth for that content.
